# Slow-and-Steady

A platformer where you have to save four different cities from getting nuked while the timers will always countdown. Made for the GMTK Game Jam 2026.

Play here: https://lionclaws.itch.io/slow-and-steady-loses-to-nuke

# Game Information

This game has timers that will always go down for every city, even when you're in the shop or the menu. There are 2 different items, one necessary for building the shield and the other is one you can get after 
saving enough cities. After every city saved, the amount of time you have gets less and less until it reaches a low enough number where you can't save it anymore. 

# About the Code

The entire game was made with the script of the engine, GDScript (very similar to Python). The amounts saying Javascript and HTML are not for this game,
but for the extension for Hackatime (called Godot Super Wakatime in the addons section). Multiple different scripts with the most complex being for the interaciton
mechanic with multiple functions combined with changes in Godot itself.
